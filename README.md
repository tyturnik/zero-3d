# Зерно — 3D-сайт кофейни

Многостраничный сайт на чистом HTML/CSS/JS и Three.js. Сборка не нужна: Vercel раздаёт файлы как есть.

## Структура

```
index.html      — разметка всех страниц (Главная, Меню, Обжарка, Адреса)
css/style.css   — стили, цвета, адаптив
js/app.js       — меню, корзина, бронь, переходы между страницами
js/scene.js     — 3D-сцена: чашка, пар, зёрна, барабан, метка
vercel.json     — настройки Vercel
```

Чтобы переделать сайт под другого клиента:
- **тексты** меняются в `index.html`;
- **меню, цены, адреса** — в начале `js/app.js` (блок «Данные»);
- **цвета** — в начале `css/style.css` (переменные `--bg`, `--acc` и т.д.);
- **3D-объекты** — в `js/scene.js`.

## Запуск на компьютере

Нужен установленный Node.js. В папке проекта выполните:

```
npx serve .
```

Затем откройте адрес, который появится в терминале (обычно http://localhost:3000).
Если просто открыть `index.html` двойным кликом, сайт тоже заработает, но лучше смотреть через сервер.

## Деплой на Vercel

### Вариант 1. Через GitHub (рекомендуется)
1. Создайте новый репозиторий на github.com, например `zerno-3d`.
2. Загрузите в него все файлы из этой папки: **Add file → Upload files**, или через git:
   ```
   git init
   git add .
   git commit -m "Zerno 3D site"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/zerno-3d.git
   git push -u origin main
   ```
3. Зайдите на vercel.com → **Add New → Project** → выберите репозиторий → **Import**.
4. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
5. Нажмите **Deploy** и через минуту получите ссылку вида `zerno-3d.vercel.app`.

После этого каждый `git push` будет автоматически обновлять сайт.

### Вариант 2. Через Vercel CLI
```
npm i -g vercel
vercel          # первый раз: войти и ответить на вопросы
vercel --prod   # выложить в продакшен
```

## Свой домен
Vercel → проект → **Settings → Domains** → добавьте домен и пропишите у регистратора DNS-записи, которые покажет Vercel.
